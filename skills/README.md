# Skills

Reusable agent skills for Cursor and Claude Code. This is the canonical location — symlink from `~/.claude/skills/` and `~/.cursor/skills/` to use globally.

## Skills

| Skill                              | Description                                                                                                                                                                                    |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [[create-skill]]                   | Create new agent skills in this library                                                                                                                                                        |
| [[gh-pr-review-resolver]]          | Address PR review comments — triage, implement fixes, push back with evidence, and post inline replies                                                                                         |
| [[pr-drafter]]                     | Drafts a complete pull request description from the git diff, linked issue, build status, and relevant internal docs — gating creation until CI is green                                       |
| [[refine-skill]]                   | Refines an existing skill by incorporating manual edits (git diffs) back into a clean SKILL.md that follows the create-skill template                                                          |
| [[review-gh-pr]]                   | Structured GitHub PR review (correctness, simplicity, readability, maintainability) and optional post to the PR via MCP or gh                                                                  |
| [[rosetta-stoner]]                 | Transliterate and translate classical, historical, and sacred texts into English-readable romanized form with line-by-line meanings in any source language                                     |
| [[write-tech-spec]]                | Collaborative architectural design partner that produces implementation-ready tech spec markdown files                                                                                         |
